# CSM Advisory AB Website

## Files
- `index.html` — page structure and content
- `style.css` — responsive Scandinavian design
- `script.js` — Swedish/English switcher, localStorage, mobile menu, FAQ, animations, validation and back-to-top

## Run locally
Open `index.html` in a browser.

## Before publishing
Replace:
- `[LÄGG TILL ORGANISATIONSNUMMER]`
- `Telefonnummer läggs till`
- `#` social links
- legal-policy placeholder links
- founder photo placeholder
- form submission handling

The contact form currently validates on the client side but does not send email. Connect it to your chosen form backend/service before launch.
